# My First Program

This project is a simple, responsive website built using HTML and CSS. It demonstrates the basics of web development, including layout, styling, and interactive hover effects.

## Features

- **Responsive Design:** Adapts to different screen sizes for a better user experience on mobile and desktop devices.
- **Hover Effects:** Interactive CSS hover effects to enhance visual appeal.
- **Clean Layout:** Simple and easy-to-understand structure for beginners.

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in your web browser to view the website.

## Technologies Used

- HTML5
- CSS3
